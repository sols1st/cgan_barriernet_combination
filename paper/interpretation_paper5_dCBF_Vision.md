# Paper 5 详细解读：面向视觉端到端自动驾驶的可微分控制障碍函数

> **论文标题**: Differentiable Control Barrier Functions for Vision-based End-to-End Autonomous Driving
>
> **作者**: Wei Xiao, Tsun-Hsuan Wang, Makram Chahine, Alexander Amini, Ramin Hasani, Daniela Rus (MIT)
>
> **核心贡献**: 将 BarrierNet (Paper 4) 扩展到视觉端到端自动驾驶，设计多级可解释架构，在 sim-to-real 环境和真实自动驾驶汽车上验证了安全车道保持和避障。

## 一、问题形式化 (Problem 1)

### 1.1 输入输出

**输入**: 前视 RGB 摄像头图像（`960×600`, `130°` 水平视场角, `30Hz`）

**输出**: 高相对度控制变量（jerk + 转向加速度），而非直接的加速度/转向角：
- `u_jerk`：加加速度
- `u_steer`：转向加速度

**为什么用高相对度控制？**
- 保证车辆状态的平滑性（乘客舒适性）
- 利用车辆的物理惯性实现精确操控
- 避免因控制指令突变导致的动力系统响应失败

### 1.2 安全约束

包括两类：
1. **车道保持**：`d_lf - d ≥ 0`（左边界），`d_lf + d ≥ 0`（右边界）
2. **避障**：`Δs² + (d-d_obs)² - r_D² ≥ 0`（障碍物圆盘覆盖）

### 1.3 训练目标

```
θ* = argmin_θ E_x[ℓ(k*(x), k(x|θ))]
```
其中 k* 是名义控制器（NMPC），k 是神经网络控制器。强调**策略蒸馏**而非纯 RL。

## 二、多级可解释端到端架构

### 2.1 设计动机

**核心挑战**：端到端训练高相对度控制器需要**大量多样化数据**。因为在相同观测下，不同速度/加速度组合对应不同的高相对度控制需求，容易造成训练混淆。

**解决方案**：多级可解释架构 —— 不同深度学习不同语义信息。

### 2.2 架构层次

```
┌──────────────────────────────────────────────────────────────┐
│              多级可解释端到端架构                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │

│       │                                                      │
│       ▼                                                      │
│  ┌─────────────────────────────────────────┐                 │

│  │  输入: RGB 960×600                       │                 │
│  └──────────────┬──────────────────────────┘                 │
│                 │                                            │
│     ┌───────────┼───────────┬────────────┐                   │
│     ▼           ▼           ▼            ▼                   │
│  ┌──────┐  ┌──────┐   ┌──────┐    ┌──────────┐              │
│  │Level1│  │Level2│   │Level3│    │  Level4  │              │
│  │位置  │  │速度  │   │加速度│    │  BarrierNet│             │

│  │  d   │  │  v   │   │  a   │    │  u_jerk  │              │

│  ┌──────────────────────────────────────┐                    │
│  │  多级监督信号 (MSE Loss)              │                    │

```

### 2.3 各层详细信息

| 层级 | 学习内容 | 监督信号 | 维度 | 角色 |
|------|----------|----------|------|------|
| Level 1 | 空间位置 | d (横向偏差), d_obs (障碍物横向位移), μ (航向误差), Δs (相对进度) | 4维 | 感知：理解"我在哪、障碍物在哪" |
| Level 2 | 运动状态 | v (车速), δ (转向角) | 2维 | 感知：理解"我动得怎样" |
| Level 3 | 参考控制 | a (加速度参考), ω (转向率参考) | 2维 | 通过导数层从 Level 2 计算 |
| Level 4 | 安全控制 | u_jerk, u_steer | 2维 | BarrierNet QP 输出 |

### 2.4 导数层的物理一致性

```
Level 2 输出 v, δ
      ↓ (数值微分 / 导数层)
Level 3 输出 a_ref = dv/dt, ω_ref = dδ/dt
      ↓ (作为 BarrierNet 的参考控制 F(z))
Level 4 BarrierNet 输出 u_jerk, u_steer
      ↓ (积分)
实际执行: a = ∫u_jerk·dt, ω = ∫u_steer·dt
```

这种设计与车辆物理动力学一致，增强了可解释性。

## 三、车辆动力学模型

使用相对于参考轨迹的曲线坐标系统（Frenet 坐标系）：

```
[ṡ ]   [ v·cos(μ+β) / (1-d·κ)   ]
[ḋ ]   [ v·sin(μ+β)              ]
[μ̇] = [ (v/l_r)·sinβ - κ·(...)  ]  +  g(x)·u
[ v̇ ]   [ a                        ]
[ ȧ ]   [ 0                        ]
[ δ̇ ]   [ ω                        ]
[ ω̇ ]   [ 0                        ]
```

其中：
- `s`: 沿轨迹的进度
- `d`: 横向偏差
- `μ`: 局部航向误差（μ = θ - φ，θ 为全局航向，φ 为参考轨迹切向角）
- `v`: 线速度
- `a`: 加速度
- `δ`: 转向角
- `ω`: 转向率
- `κ`: 参考轨迹曲率
- `l_r, l_f`: 车辆重心到后/前轴的距离
- `β = arctan(l_r/(l_r+l_f) · tan δ)`: 侧滑角

**状态维度**: 7 维  
**控制维度**: 2 维 (jerk + 转向加速度)

## 四、可微分 CBF 设计（障碍物覆盖策略）

### 4.1 大圆盘覆盖方法

**核心挑战**：自动驾驶中障碍物数量不固定，但 BarrierNet 需要预定义约束数。

**解决方案**：预设 N 个覆盖圆盘（N = 最大可能障碍物数）：

```
无实际障碍物时:
  圆盘移到道路外 → 充当车道保持约束

有障碍物时:
  按距离排序障碍物 → 对应排序圆盘覆盖
  每个圆盘生成一个 CBF 约束
```

**偏置圆盘的位置**取决于障碍物相对于车道中心的方向，允许大圆盘覆盖而不引入过度保守性。

### 4.2 具体 dCBF 定义

#### 车道保持（2 个约束）

```
b_lf^left  = d_lf - d    ≥ 0
b_lf^right = d_lf + d    ≥ 0
```

其中 `d_lf` 是预设的车道边界（相对于车道中心的横向距离）。

#### 避障（N 个约束）

```
b_obs = Δs² + (d - d_obs)² - r_D²  ≥ 0
```

其中：
- `Δs`: 自车与障碍物的相对沿路进度
- `d_obs`: 障碍物相对于车道中心的横向位移
- `r_D`: 覆盖圆盘半径

### 4.3 CBF 可行性保证

为确保 QP 始终有解：
- 训练时放松/去除控制边界
- 使用满足安全约束的名义控制标签
- 推理时加入控制边界，通过可行性约束保证

## 五、训练数据生成管线

### 5.1 数据来源

真实世界数据 + VISTA 数据驱动仿真器的合成数据增强：

```
真实驾驶数据 (~2小时)
     │
     ▼
VISTA 仿真器 (数据驱动, 非模型驱动)
     │  随机初始化自车和障碍车配置
     │
     ▼
NMPC 名义控制器 (离线, 20步滚动时域)
     │  输出: 最优 (u_jerk, u_steer)
     │  同时记录: 状态 (d, d_obs, μ, Δs, v, δ, a, ω)
     │
     ▼
合成 RGB 图像 (VISTA 渲染, 各种环境条件)
     │
     ▼
总训练数据: ~400k 图像
```

### 5.2 损失函数与训练细节

```
总损失 = MSE_loss(v, δ) + MSE_loss(d, d_obs, μ, Δs) + MSE_loss(a, ω)
       + 各层中间监督信号

训练技巧:
- 约束 v, δ 的导数以稳定训练 (bound the derivative)
- 无/远障碍物时限制 Δs, d_obs 的损失 (cap loss)
```

## 六、每个时间步的详细数据流

### 6.1 训练阶段

```
时间步 t:
─────────

输入: 前视 RGB 图像 o_t (960×600×3)

1. CNN/LSTM 编码:
   features = Encoder(o_t)

2. 状态估计 (Level 1):
   [d̂, d̂_obs, μ̂, Δ̂s] = StateHead(features)

3. 运动估计 (Level 2):
   [v̂, δ̂] = MotionHead(features)

4. 参考控制 (Level 3):
   â_ref = dv̂/dt (数值微分)
   ω̂_ref = dδ̂/dt

5. 惩罚函数预测:
   p_i(z) = PenaltyHead(features)    // 来自 CNN/LSTM 的中间特征

6. BarrierNet QP:
   min_{u_jerk, u_steer} ½u^T H u + F^T u
   s.t. dCBF 约束 (车道保持 + 避障, 用 p_i(z) 参数化)
   
   F = [â_ref, ω̂_ref]^T (参考控制)
   
   输出: [û_jerk, û_steer]

7. 多级损失计算:
   L_state = MSE(d̂, d) + MSE(d̂_obs, d_obs) + MSE(μ̂, μ) + MSE(Δ̂s, Δs)
   L_motion = MSE(v̂, v) + MSE(δ̂, δ)
   L_control = MSE(û_jerk, u_jerk^gt) + MSE(û_steer, u_steer^gt)
   L_total = L_state + L_motion + L_control
```

### 6.2 推理/部署阶段（真实车辆）

```
时间步 t (实际 30Hz = Δt ≈ 33ms):
─────────

1. 摄像头捕获: o_t (RGB 960×600)
2. 神经网络前向传播:
   a. CNN/LSTM → features
   b. 状态估计 → d̂, d̂_obs, μ̂, Δ̂s
   c. 运动估计 → v̂, δ̂
   d. 惩罚函数 → p_i(z)
   e. BarrierNet QP 求解 → û_jerk, û_steer
3. 执行器:
   a_{cmd} = ∫ û_jerk · dt  (积分得到加速度指令)
   ω_{cmd} = ∫ û_steer · dt (积分得到转向率指令)
4. 底层控制器执行 a_{cmd}, ω_{cmd}

实时性: BarrierNet QP < 0.01s → 总计在 30Hz 内可行
```

VISTA 2.0：数据驱动仿真器
- 使用真实世界数据合成新视角
- 支持不同天气/光照/季节条件
- 实现接近零 sim-to-real gap 的策略迁移

### 7.3 实验场景

| 场景 | 测试环境 | 测试内容 |
|------|----------|----------|
| 车道保持 | VISTA | 1000 episodes, 200步, 随机起点 |
| 避障 | VISTA | 与 ado-car 的碰撞避免 |
| 急转弯 | 真实车辆 + 雪地 | 左转和右转的离道风险 |

| 真实避障 | 真实车辆 | 真实停放车辆 |

### 7.4 关键实验结果

#### 车道保持 (Fig. 5)
- 有车道保持 CBF 的 BarrierNet 显著降低偏离车道中心 >1m 的概率
- CBF 的 Lyapunov 性质提供"拉力"将车辆拉回车到中心

#### 避障 (Table I)

| 方法 | 碰撞率 | 最小间隙 |
|------|--------|----------|
| 无 dCBF | 0.53 | 0.43m |
| 有 dCBF | 0.28 | 0.55m |
| 有 dCBF + GT状态 | 0.03 | 0.61m |

碰撞率从 53% 降至 28%（不完美状态估计），使用真值状态降至 3%。

#### 状态估计误差分析 (Fig. 7)
- `d_obs` 估计误差对碰撞率影响最大（判断障碍物在左侧还是右侧）
- 随状态估计误差增大，碰撞率上升

#### 真实车辆实验
- 雪地急转弯：有车道保持 CBF 的 BarrierNet 保持车辆在路面上
- AR 避障：BarrierNet 创造更大的安全间隙
- 真实避障：参考控制可能失败时，BarrierNet 的 dCBF 约束被激活并纠正

#### 惩罚函数的适应行为 (Fig. 9)
- `p_1(z), p_2(z)` 在接近障碍物时自适应变化（降低以收紧约束）
- 离开障碍物后恢复到较大值（放松约束）
- 两种不同的训练模型学习到不同的 p_i 变化模式（一对多映射）

## 九、关键设计技巧与工程细节

### 9.1 多圆盘覆盖策略的优势

- 不需要动态创建/删除 CBF 约束
- 冗余约束（无实际障碍物时）不影响系统（不激活）
- 排序覆盖保证一致性

### 9.2 VISTA 数据驱动仿真

- 与模型驱动仿真不同，VISTA 使用真实世界数据合成新视角
- 保留真实纹理、光照、几何
- 大幅降低 sim-to-real gap

### 9.3 训练稳定性技巧

- 对 v 和 δ 的导数进行约束（bound），避免参考控制剧烈变化
- 远距离/无障碍物时限制 Δs 和 d_obs 的损失贡献

### 9.4 可行性约束

论文中引用的可行性充分条件（来自 Xiao et al., Automatica 2022）可在 BarrierNet 输入到未见过的区域时保证 QP 有解。

## 十、关键数学原理

### 10.1 Frenet 坐标系

将车辆运动从全局 2D 坐标转换到沿参考轨迹的 1D 坐标系统：
- 沿轨迹进度 s 和横向偏差 d 解耦
- CBF 约束在 Frenet 坐标系中定义更自然（车道保持 = |d| ≤ d_lf）

### 10.2 高相对度 CBF

避障约束 `b_obs = Δs² + (d-d_obs)² - r_D² ≥ 0` 相对于动力学 (12) 的相对度为 2。

因此需要 HOCBF：定义 `ψ_0 = b_obs, ψ_1, ψ_2`，控制出现在 `ψ_2` 的 Lie 导数中。

### 10.3 dCBF 参数化

每个约束 j 的 HOCBF 包含 m 个可学习惩罚函数 `p_i(z)`，控制约束的松紧程度。

## 十三、局限性

1. 需要大量标注的训练数据（~400k 图像 + 精确状态标注）
2. 视觉状态估计的不完美是碰撞的主要原因（见表 I 的 GT 对比）
3. 仅在单障碍物场景中充分验证
4. 所有图像需要灰度化和降采样
5. 在恶劣天气下（大雪覆盖路面边界）车道保持性能可能下降
6. 需要 dGPS 提供精确的真值标注用于训练
