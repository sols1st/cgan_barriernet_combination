# Paper 2 详细解读：SPVT — 具有半概率安全保证的视觉神经网络控制器学习

> **论文标题**: Learning Vision-Based Neural Network Controllers with Semi-Probabilistic Safety Guarantees
>
> **作者**: Xinhang Ma, Junlin Wu, Hussein Sibai, Yiannis Kantaros, Yevgeniy Vorobeychik (Washington University in St. Louis)
>
> **核心贡献**: 提出半概率验证 (SPV) 框架，结合可达性分析与条件生成网络和分布无关尾界，高效可扩展地验证视觉神经网络控制器；并设计自适应训练数据策略与课程学习来合成安全控制器。

## 一、问题形式化

### 1.1 系统模型

离散时间动力系统：
```
s_{t+1} = f(s_t, u_t)       -- 系统动力学（已知）
o_t = h(s_t, ω)             -- 观测映射（未知）
s_0 ∼ D                     -- 初始状态分布（未知）
ω ∼ Ω                       -- 环境变化分布（未知）
```

其中 `h` 接收环境参数 `ω`，建模未观测的环境变化源（光照、纹理等）。

**关键设定**：执行时仅观测 `o_t` 可知，状态 `s_t` 不可观测。

### 1.2 安全规范

- 安全谓词 `P(s)`：指示状态 s 是否安全
- 安全谓词 `P(τ)`：指示集合 τ 中所有状态是否安全
- 安全通常用线性不等式描述，τ 为多面体

### 1.3 半概率安全概念

与 SafePVC 的"全概率"不同，SPVT 采用**半概率**：
- 对初始状态分布 D：**概率性**保证（用有限样本 + 分布无关尾界）
- 对环境变化 ω：**最坏情况**保证（对所有可能的 ω）

```
半概率 = 概率(初始状态) + 最坏情况(环境变化)
```

## 二、视觉观测模型近似

### 2.1 cGAN 生成器

用条件生成模型 `g(s, z)` 近似 `h(s, ω)`：
- `z ∈ Z` 为随机潜变量（均匀或高斯分布）
- 训练方式：cGAN 或条件扩散模型

### 2.2 核心假设（Assumption 1）

```
sup_{s,ω} inf_z ||h(s, ω) - g(s, z)|| ≤ ε
```

**含义**：对任何真实状态-观测对 `(s, h(s,ω))`，存在潜变量 z 使得生成器输出与真实观测误差不超过 ε。

**验证**：通过梯度优化找到最小化 MSE 的最佳 z，在 4 个场景下验证（见图 3），潜变量维度从 2 到 64。

### 2.3 关键推论（Theorem 1）

在 Assumption 1 下：
```
Reach_K(s_0, π) ⊆ Reach_K(s_0, π, g)
```
即用生成器 g 计算的 K 步可达集是真实可达集的**过近似**：
- 真实可达集 `Reach_K(s_0, π)` 用真实观测 h
- 近似可达集 `Reach_K(s_0, π, g)` 用生成器 g，考虑 ε-ball 内的所有观测

**证明**：归纳法。在 Assumption 1 下，对每个真实观测 o，存在 z 使得生成器输出接近 o（误差 ≤ ε）。因此真实下一状态在近似可达集中。

## 三、半概率验证 (SPV) 框架

### 3.1 核心思想

传统 K-可达性验证对所有初始状态 `S_0` 保证安全 → **过于保守，可扩展性差**。

SPV 的平衡方案：
```
对初始状态 s_0 ∼ D:  概率性（有限样本 + 分布无关尾界）
对环境变化 ω ∼ Ω:    最坏情况（对所有 ω）
```

### 3.2 K 步可达集计算

用生成器 g 定义的近似状态传播：

```
Ŝ_0(s_0, π) = {s_0}
Ŝ_{t+1}(s_0, π) = {f(s, π(o)) | ||o - g(s, z)|| ≤ ε, s ∈ Ŝ_t, z ∈ Z}
```

**关键**：ε-ball 覆盖了 Assumption 1 的近似误差，保证真实状态被包含。

K 步可达集：
```
Reach_K(s_0, π, g) = ∪_{t=0}^K Ŝ_t(s_0, π)
```

### 3.3 分布无关尾界（Theorem 2）

从未知分布 D 采样 N 个 i.i.d. 初始状态 `{s_i}_{i=1}^N`：

```
设 V = {s_i | P(Reach_K(s_i, π, g))} 为已验证安全的初始状态子集
```

则对整体分布 D：
```
Pr_{s∼D}[P(Reach_K(s, π))] ≥ |V|/N - √(1/(2N) · log(2/δ))
```
以概率 ≥ `1-δ` 成立。

**推导**：
- 由 Chernoff-Hoeffding 界：`Pr(|α̂ - α| ≥ ε) ≤ 2e^{-2Nε²}`
- 其中 α 是真实安全概率，α̂ = |V|/N 是经验安全率
- 设 δ = 2e^{-2Nε²}，解得 ε = √(1/(2N) · log(2/δ))
- 由 Theorem 1，近似安全 ⇒ 真实安全，安全概率下界得证

**置信度参数**：实验中设 δ = 0.05。

## 四、安全控制器合成

### 4.1 训练目标

```
max_θ Pr_{s∼D}[P(Reach_K(s, π_θ))]
```

转化为可操作的代理目标：
```
max_θ Σ_i P(Reach_K(s_i, π_θ, g))
```
即：在有限初始状态样本上，最大化可验证安全的状态比例。

### 4.2 安全分数与边界

设 `σ(Reach_K(s_i, π_θ, g))` 为安全分数（如车道跟踪中的横向误差）。

使用 α,β-CROWN 计算可微分的声音上下界：
```
σ_K^{(i)} ≤ σ(Reach_K) ≤ σ̄_K^{(i)}
```

### 4.3 损失函数

```
L(s_0, θ) = λ_1 · L_perf(s_i, θ) + λ_2 · L_safety(s_i, θ)
```

#### 性能保持损失 `L_perf`
- 监督学习：与预训练 anchor 控制器的 ℓ2 损失
- RL：策略梯度目标

#### 安全损失 `L_safety`（核心创新）

```
L_safety(s_i, θ) = (|σ̄_K^{(i)}| + |σ_K^{(i)}|) / (K - 1)
```

**设计直觉**：测量可达区域在 K 步内的**变化率**，而非绝对值。
- 变化率大 → 状态快速漂移 → 不安全趋势 → 高损失
- 变化率小 → 状态稳定 → 安全趋势 → 低损失

这比直接用安全边界值更平滑、更适合梯度优化。

## 五、自适应训练数据策略

### 5.1 数据结构

训练数据 `S_l = S_0 ∪ S_A`：
- **S_0**：随机初始状态集（固定大小）
- **S_A**：安全关键状态优先队列（固定大小，动态更新）

S_0 和 S_A 保持不相交。

### 5.2 安全关键状态选择

用安全参数 `η^{(i)}` 量化状态的安全性挑战程度：

```
η^{(i)} = L_safety^{(i)} + max(0, |σ̄_K^{(i)}| - β) + max(0, |σ_K^{(i)}| - β)
```

- 第一项：安全损失（可达集变化率）
- 第二/三项：惩罚超出安全阈值 β 的上下界

### 5.3 加权采样（Efraimidis & Spirakis 方法）

```
w_i = e^{α · η^{(i)}}          // 权重（α为温度超参）
k_i = w_i^{1/U_i}, U_i ∼ Uniform(0,1)  // 随机键
选取 top L_A 个最大 k_i 值 → 加权无放回采样
```

每批训练数据 = `⌊p·L⌋` 来自 S_A + 其余来自 S_0。

### 5.4 优先队列更新

```
训练开始:  S_A = ∅
预热阶段:  将每批中 m% 最具挑战性的数据加入 S_A
正式训练:  从 S_A 中采样 p 比例的数据
动态调整:  若安全改善或出现新挑战数据，更新 S_A
```

## 六、课程学习 (Curriculum Learning)

逐步增加验证视野 K：
```
K₁ < K₂ < ... < K_{n-1} < K_n = K
```

- 先训练短视野（如 K=5）的可验证安全性
- 在短视野收敛后，渐进增加到更长视野
- 目的：稳定训练，使控制器逐步学习更复杂的安全约束

---

## 七、验证流程中的可达性计算

```
对每个初始状态 s_i，用 α,β-CROWN 迭代验证 K 步:

步骤 0: Ŝ_0 = {s_i}
        ↓
步骤 t: Ŝ_t 中的状态 → π(g(s, z)) → 控制 → f → 下一状态区域
        其中考虑: (1) z ∈ Z 所有潜变量
                  (2) ε-ball 观测误差
        ↓
        检查 Ŝ_{t+1} 是否与不安全集相交
        ↓
步骤 K: 得到 Reach_K(s_i, π, g)
        若所有状态安全 → s_i 验证通过
```

## 八、每个时间步的数据流

### 8.1 训练阶段（每个训练迭代）

```
批数据 {s_i}:

1. 前向传播 (每个 s_i):
   For t = 0 to K-1:
     o_t = g(s_t, z)                     // 生成器产生观测（对所有 z）
     u_t = π_θ(o_t)                      // 策略输出动作
     s_{t+1} = f(s_t, u_t)              // 动力学传播
     [可选] 用 α,β-CROWN 计算 σ 的上下界
   
2. 计算安全损失:
   L_safety = (|σ̄_K| + |σ_K|) / (K-1)
   
3. 计算总损失:
   L = λ_1 · L_perf + λ_2 · L_safety
   
4. 反向传播更新 θ

5. 更新自适应数据集:
   计算 η^{(i)} → 更新 S_A 优先队列
```

### 8.2 推理/部署阶段

```
时间步 t:
─────────
输入: o_t (真实摄像头图像)
1. 控制器: u_t = π_θ(o_t)
2. 执行: s_{t+1} = f(s_t, u_t)

安全保证（离线已验证）:
  Pr_{s_0∼D}[安全K步] ≥ |V|/N - √(1/(2N) · log(2/δ))
```

## 九、网络结构汇总

### 9.1 cGAN 生成器 g(s, z)
- **路径跟踪实验**: 4 层全连接，256 神经元/层，ReLU + Tanh
- **无人机实验**: 卷积生成器（更复杂）
- **潜变量维度**: 10（路径跟踪），可调整（消融实验中 2-64）
- **输出**: 8×16 灰度图（路径跟踪），64×64 灰度图（无人机）

### 9.2 cGAN 判别器
- **架构**: 卷积神经网络
- **正则化**: 谱归一化 (所有层) + 正交正则化 (生成器)
- **初始化**: 正交初始化

### 9.3 控制器 π_θ
- **路径跟踪**: 监督学习（模仿 PID 控制器）
  - 学习率: 0.0002, 批大小: 128, 100 epochs
- **无人机**: PPO
  - γ=0.99, 学习率 0.0003→0.0002, 总步数: 200k + 200k

### 9.4 α,β-CROWN 验证器
- 用于计算安全分数的可微分上下界
- 逐时间步迭代：计算输出界 → 动力学传播 → 下一时间步状态界

## 十、关键数学原理

### 10.1 Chernoff-Hoeffding 界

对 i.i.d. 随机变量 `X_i ∈ [0,1]`，经验均值 `X̄_N`：
```
Pr(|X̄_N - E[X]| ≥ ε) ≤ 2e^{-2Nε²}
```

在 SPV 中：
- `X_i` = 指示变量 I[P(Reach_K(s_i, π, g))]
- `X̄_N` = |V|/N（经验安全率）
- `E[X]` = α = Pr_{s∼D}[P(Reach_K(s, π, g))]

### 10.2 安全概率下界推导

```
设 α = Pr_{s∼D}[P(Reach_K(s, π, g))]     // 近似系统的安全概率
设 α̂ = |V|/N                               // 经验安全率

由 Hoeffding: Pr(α ≥ α̂ - ε) ≥ 1 - δ, 其中 ε = √(log(2/δ)/(2N))

由 Theorem 1: P(Reach_K(s, π, g)) ⇒ P(Reach_K(s, π))
  因此: Pr_{s∼D}[P(Reach_K(s, π))] ≥ α ≥ α̂ - ε
```

### 10.3 ε-ball 过近似

Assumption 1 保证了 ε-覆盖性质：
```
∀s,ω ∃z: ||h(s,ω) - g(s,z)|| ≤ ε
```

因此，对每个真实观测 `h(s,ω)`，生成器能在 ε-ball 内找到匹配。在所有 z ∈ Z 上取并集，保证真实可达集被包含。

## 十一、实验设计

### 11.1 四个实验场景

| 场景 | 状态空间 | 图像尺寸 | z维度 | 训练数据量 |
|------|----------|----------|-------|-----------|
| X-Plane 11 飞机着陆 | d∈[-10,10]m, θ∈[-0.5,0.5]rad | 8×16 | 10 | 20,000 |
| CARLA 车道跟随 | d∈[-0.8,0.8]m, θ∈[-0.15,0.15]rad | 8×16 | 10 | 20,000 |
| F1Tenth 物理平台 | 同CARLA | 8×16 | 10 | 400 (微调) |
| Airsim 无人机导航 | 3D位置+四元数姿态 | 64×64 | 10 | 20,000 |

### 11.2 基线方法

| 方法 | 类型 | 安全保证 |
|------|------|----------|
| RESPO | 安全RL + 可达性分析 | 经验性 |
| SAC-RCBF | 鲁棒CBF | 形式化（在线QP） |
| VSRL | 增量可达性验证 + 安全RL | 形式化（有限视野） |
| SPVT (本文) | 半概率验证 | 形式化（半概率） |

### 11.3 评估指标

1. **经验性能**: 100个随机初始状态，200步仿真，累计奖励
2. **安全概率下界**: 随 K 变化的 `Pr(safe) ≥ bound`
   - 2000 个初始状态 i.i.d. 采样
   - δ = 0.05

### 11.4 关键结果

- SPVT 在所有场景中保持**最强经验性能**（特别是高维无人机场景）
- SPVT 在所有场景中提供**最高的安全概率下界**
- VSRL 在无人机场景中**完全失败**（全输入空间验证计算不可行）
- 消融实验：cGAN 优于 Diffusion 模型（在 X-Plane 中）

## 十二、论文独特之处

1. **半概率验证概念**：概率（初始状态）+ 最坏情况（环境变化）的混合
2. **分布无关尾界**：用 Chernoff-Hoeffding 从不完整初始状态分布样本推导全体保证
3. **自适应训练数据**：优先队列动态维护安全关键状态，加权采样
4. **可微分安全代理损失**：基于 α,β-CROWN 的可达集变化率
5. **课程学习**：逐步增加验证视野 K，稳定训练
6. **物理平台验证**：F1Tenth 实车实验

## 十三、与 SafePVC (Paper 1) 的关键区别

| 维度 | SafePVC | SPVT |
|------|---------|------|
| 安全保证类型 | 全概率 (infinite horizon) | 半概率 (finite horizon K) |
| 安全证书 | SBC (鞅理论) | 无证书，直接可达性验证 |
| 验证工具 | α,β-CROWN + Lipschitz 网格 | α,β-CROWN 可达性 |
| 初始状态处理 | 全初始集保证 | 有限样本 + 尾界 |
| 环境变化处理 | 随机分布（Δs∼μ） | 最坏情况（∀ω∈Ω） |
| 训练目标 | SBC 条件满足 | 安全分数可达集变化率 |
| 控制策略更新 | SBC 反例引导 | 自适应数据 + 安全损失反向传播 |

## 十四、局限性

1. K 步有限视野保证（非无限时间）
2. 需要低分辨率灰度图像
3. 仅处理标量安全分数场景
4. cGAN 训练在小数据集上可能出现模式坍塌
5. Assumption 1 在实践中可能过于乐观
